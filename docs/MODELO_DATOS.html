Modelo de Datos BARB

14 tablas núcleo de la base Postgres, con sus 28 claves foráneas. Salen de pg_dump; se omiten auditoría, transacciones, sesiones, embeddings, reportes y tablas de debug.

  • Empresa y usuarios
  • Planta, máquina, sensores, topología
  • Mantenimiento: avisos, OT, repuestos
  • Documentos y chat IA
  • FK empresa_id (aislamiento multi-tenant)
  • Otras FK (la flecha apunta a la PK)

Pasa el cursor, enfoca o toca una tabla para resaltar sus relaciones. Toca de nuevo para soltar. En pantallas angostas el diagrama se desplaza de lado.

Flujo de una falla

aviso_falla lo reporta un usuario sobre una máquina. El supervisor lo descarta o genera una orden_trabajo (aviso_falla_id). La OT consume piezas vía ot_repuesto.

Chat y documentos

documento se parte en documento_chunk para la búsqueda del chat. Un documento y una conversación pueden fijarse a una máquina (maquina_id).

Omitido a propósito

En orden_trabajo se ocultan diagnostico_id y reporte_id (apuntan a tablas fuera del diagrama). usuario.empresa_id es NULL solo para super_usuario.
